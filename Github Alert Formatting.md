# Github Alerts Formatting on Markdown

Use the following markups for Github Style alerts in Markdown. 

Default Colors for GitHub Alerts
In GitHub Flavored Markdown (and compatible renderers), each alert type maps to a specific accent color and icon:

> [!NOTE] 
> Renders in Blue (accent border, background tint, and info icon).

> [!TIP] 
> Renders in Green (accent border, background tint, and lightbulb icon).

> [!IMPORTANT] 
> Renders in Purple (accent border, background tint, and exclamation icon).

> [!WARNING] 
> Renders in Yellow / Amber (accent border, background tint, and warning triangle).

> [!CAUTION] 
> Renders in Red (accent border, background tint, and octagonal stop icon).

**Points to note**

1. No blank lines between the popup type (Note, Caution etc) and the FIRST line below. You can have blank lines thereafter.
2. It is a callout, so preceed each new para with a `>`.
3. You will need to install the `Markdown Preview for Github Alerts` extension by `Yahya Batulu` to enable this preview. Restart VS Code after installation.
