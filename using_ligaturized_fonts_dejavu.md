# How to use Ligaturized DejaVu Sans Mono fonts

The traditional DejaVu Sans Mono fonts do not support the ligatures I have set in my VSCode User `settings.json`.

You can download Ligaturized fonts of most of the popular monospaced fonts from [this website](https://github.com/ToxicFrog/Ligaturizer/releases). Download the `LigaturizedFonts.zip` or `LigaturizedFontsWithChars.zip` and install on your Winsdows or Linux system.
